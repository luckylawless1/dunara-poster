DUNARA — a travel poster for a place that isn't there: a lighthouse standing in a sand sea, its beam the only light for a night's walk in any direction. A small Python program draws the whole poster from code — dusk sky, dunes, lighthouse, caravan — and writes it to /output/entry.png. No assets, no network, deterministic.

## Run it

```sh
python3 main.py
```
